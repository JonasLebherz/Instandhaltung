# Herkunft

- Werkzeug: graphify, https://github.com/Graphify-Labs/graphify (Original: github.com/safishamsi/graphify), PyPI-Paket `graphifyy`.
- Im Repository liegt nur dieser kurze Starter (`SKILL.md`). Die eigentliche Anleitung installiert `graphify install`
  beim Aufruf nach `~/.claude/skills/graphify/` – das Original nennt keine Lizenz, deshalb wird sie nicht hierher kopiert.
- Hinweis: graphify liest die Projektdateien und schickt Inhalte über Claude (Unteragenten) zur Auswertung – keine
  Zugangsdaten (`.env*`) einlesen lassen.
